A conversão de escalas termométricas é fundamental em processos industriais, meteorologia e física experimental. No **Scalar**, nossa ferramenta utiliza as constantes exatas de conversão para garantir resultados precisos em todas as escalas.

Basta inserir o valor em qualquer campo para obter a correspondência imediata nas outras unidades.

## As Escalas Termométricas

Entender a base de cada escala é essencial para aplicações científicas:

* **Celsius (°C):** Baseada nos pontos de congelamento (0 °C) e ebulição (100 °C) da água sob pressão atmosférica normal.
* **Fahrenheit (°F):** Criada por Daniel Fahrenheit, ainda é o padrão nos EUA para clima e culinária.
* **Kelvin (K):** A unidade fundamental de temperatura no Sistema Internacional (SI). Diferente das outras, ela não usa "graus", mas sim uma escala absoluta.

## O Zero Absoluto (0 K)

Na física, a temperatura é uma medida da agitação das moléculas. O **Zero Absoluto** é o estado teórico onde essa agitação cessaria completamente. Isso ocorre em **-273,15 °C**. Por isso, a escala Kelvin nunca possui valores negativos.

### Fórmulas de Conversão

Se você precisar calcular manualmente, utilize as seguintes relações matemáticas:

1.  **Celsius para Fahrenheit:** $$F = (C \times 1.8) + 32$$
2.  **Celsius para Kelvin:** $$K = C + 273.15$$
3.  **Fahrenheit para Celsius:** $$C = (F - 32) \div 1.8$$
