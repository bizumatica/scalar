Documentação e Teoria

A conversão entre sistemas numéricos é a base da computação moderna. No Scalar, você pode alternar entre as bases mais utilizadas na engenharia:

  • Decimal (Base 10): O padrão humano.
  • Binário (Base 2): A linguagem das portas lógicas.
  • Hexadecimal (Base 16): Essencial para endereçamento de memória e cores.
  • Octal (Base 8): Frequentemente usado em permissões de sistemas Unix.

Basta digitar em qualquer campo para que todos os outros sejam calculados instantaneamente.
